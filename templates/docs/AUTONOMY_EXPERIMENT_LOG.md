# Autonomy Experiment Log

This project uses recurring Codex automation as a high-agency software-development workflow.

Periodically record:

- what the automation has been doing
- good autonomous decisions
- questionable autonomous decisions
- repeated failure modes
- stale or bloated instructions
- ways to improve future runs
- whether work is compounding toward a better product
- whether the workflow seems reusable for other projects

This should not become pure meta-work. The default mode remains building the product.
